# FOS-Notenrechner

A small web project to calculate my grade average for school (0–15 point system). I built this to practice HTML, CSS, and basic JavaScript (DOM manipulation and localStorage).

## Features
- Add subjects and points (0–15)
- Automatic average calculation
- Saves grades in the browser using `localStorage`
- Clear all entries at once

## How to run
Just open `index.html` in any web browser.
